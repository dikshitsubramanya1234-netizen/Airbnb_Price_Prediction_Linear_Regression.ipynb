Airbnb_Price_Prediction_Linear_Regression.ipynb

*Project Overview

This project uses a Linear Regression machine learning model to predict Airbnb listing prices based on different listing features.
The project includes data cleaning, exploratory data analysis (EDA), outlier treatment, feature encoding, model training, and model evaluation.

*Objective

The objective of this project is to build a Linear Regression model that predicts the price of an Airbnb listing and analyses the factors that affect listing prices.

*Dataset

The dataset contains information about Airbnb listings in New York City, including:
Neighbourhood group,
Neighbourhood,
Room type,
Minimum nights,
Number of reviews,
Reviews per month,
Availability,
Listing price.

Dataset source: Airbnb New York City 2019 dataset from Kaggle.

*Machine Learning Model

The Linear Regression algorithm was used to predict Airbnb listing prices.

The dataset was divided into training and testing data before model training.

Root Mean Squared Error (RMSE)

Visualizations

*Business Insights

The analysis helps identify factors that may influence Airbnb listing prices, such as room type, location, availability, and customer reviews.
